정직 문구와 리스크 (§16)

  • Phase 3 는 skill 을 더하지 않는다. 어떤 후보도 보정 VIX 위에 측정 가능한 Brier 이득이 없다(M3→p3_A −0.0002, ens(M3,H) +0.0000, M4a 무이득, 폭/신용 −0.055). 가치는 비중 규칙·시나리오·구간·트랙레코드·킬 장치다.
  • Phase 2 의 공식 결과가 Phase 3 의 전제다. model_p2.json 이 info_only 이면 유효 모드가 info_only 이므로 비중·상태 카드가 뜨지 않는다. 이 결정은 Phase 3 코드가 아니라 장부에서 내려진다.
  • 비중 규칙의 가격: σ_T 10% 에서 보유보다 ~3.6pp/년 낮고 달력연도의 ~90% 에서 뒤진다; 현금 0%(+0.6pp/년 미반영); 5bp 는 분기별로 늦게 실행하는 가족의 실제 마찰(중개·세금)을 과소평가한다.
  • 완만한 약세장 실패 모드: 2000~02 변동성 단독 −30.7~−34.6%(σ_T 10%); k_slow 3.5 는 한 에피소드로 보정한 상수다 — 예산은 보장이 아니다. 저변동 급락(2018-02, 2020-02 첫 주)은 규칙이 반응하기 전에 맞는다.
  • 바닥의 대가: 곱 뒤 0.25 재클립은 MaxDD 를 −17.9% 에서 −23.5% 로 올린다(변동성 단독과 같다). 상태 배수의 낙폭 기여는 바닥 없이만 나타나고 그 형태는 2008~09·2020 에 사실상 퇴장(비중 0.05~0.10)이었다.
  • 모든 비중 상수는 post hoc(λ, 격자, 밴드, 리듬, k_slow, 바닥 처리; ~40 변형). 유지 조건 (a)·(b) 는 근소해 공식 수치에서 뒤집힐 수 있다 — 그러면 카드가 숨겨지고 장부만 쌓인다.
  • 킬룰 검정력(p_p2, 주간 자기검사 재생성 · 창 223): 이 규칙은 과거 36개월 창에서 이 모델을 12% 오기각하고 '검증' 은 20% 에서만 준다; 정보 없는 같은 분포의 모델은 79%, 기후학+잡음은 100% 기각한다. 2단계 해석은 문자 그대로보다 엄격하다(#7).
  • 소표본은 영구 조건: 연 ~12 독립 창·~1 에피소드. 3·6개월 skill 은 잡음(10/90분위 ±0.8)이라 표시하지 않는다 — n_eff < 6 에 BSS 없음, 판정일 전 판정어 없음은 코드가 강제한다(§8.4).
  • HMM: 라벨 스위칭·EM 국소해·지속성 0.98 이라 급락을 늦게 본다. 점유 43% 는 '위기' 가 아니라 '고변동 상태'. 비지도 12개도 파라미터로 공개하며 생산 확률에는 들어가지 않는다.
  • 데이터 개정: Yahoo 조정 종가 재다운로드가 σ̂·P_high·비중 이력을 조금 바꾼다 → D10 이 불일치를 세고 D7 은 daily 를 실패시킨다; 장부는 기록이며 다시 쓰지 않는다.
  • 결합 위험: 열 이름과 spec_sha256·registry_sha·sizing_sha 가 계약이다. 불일치는 exit 1, 대체 없음. 킬은 model_p2.json 을 건드리지 않고 유효 모드의 AND 로만 작동한다.
  • 홀드아웃: 2024-09-01~ 는 unlock 파일 없이 채점하지 않는다. 그림자 멤버의 홀드아웃 점수는 정보일 뿐 채택에 쓰지 않으며, 신선 블록은 라이브 시작부터만 센다.
  • 제품 위험: 확률·상태기계·변동성 규칙 세 겹은 v0 톤보다 설명이 어렵다 → 카드는 한 숫자·한 문장으로 시작한다. 시나리오 셀은 얇다(reduce n_eff 12, 에피소드 33/11/4) — 회색·풀링 규칙은 코드가 강제한다.
  • 계산: 주간 +< 4분, 일간 +< 5초; 새 의존성 없음(numpy EM).
